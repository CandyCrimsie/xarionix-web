# Рабочая область карты

Новые компоненты используют установленный Spartan NG 1.3.4, внешние HTML-шаблоны,
Angular Signals и существующие MapLibre renderer/иконки. Новых UI-библиотек нет.
Backend-схема и точная миграция: `xarionix-erp/docs/map-workspace.md`.

## Интерфейс

- Единая компактная верхняя glass-панель: закрыть, добавить точку/кабель,
  фильтры, слои, легенда. Управление доступно через русские tooltip/aria labels.
- Одновременно открыта одна панель. Повторное нажатие, outside, Escape закрывают
  её, не сбрасывая фильтры. Закрывающий жест по карте поглощается до hit-testing
  и инструментов размещения, следующий самостоятельный жест работает обычно.
- Легенда перенесена наверх; старой нижней копии нет. Образцы цветов, штрихов и
  статусов используют тот же `map-line-styles.ts`, что и реальные слои MapLibre.
- Слои общие для компании, checkbox-видимость — персональная. Группы имеют
  tri-state; ручной состав меняется в паспорте объекта/линии. Динамический слой
  использует адресные сущности, типы, среду и статус, не произвольный текст SQL.
- Развёртывание нижней правой кнопкой переносит **тот же** Angular host/MapLibre
  в CDK DomPortal overlay с p-4, scroll block и focus trap. Камера, bearing,
  pitch и выбор сохраняются. Escape сначала закрывает вложенную форму/popover,
  затем карту; сворачивание возвращает фокус кнопке. ResizeObserver и RAF resize
  следуют реальному размеру контейнера. Второй WebGL-контекст не создаётся.
- Паспорт загружается только при открытии, отдельно от viewport. Режимы просмотра
  и редактирования; ошибка оставляет текст, expected versions защищают запись.
  Название/описание/статус кабеля не дублируются в произвольном JSON.

## Состояние и запросы

`MapWorkspaceState` создаётся на одну открытую карту. Он хранит только определения
слоёв/настройки, не GeoJSON. GET настроек и слоёв — одна инициализация контекста.
Сохранение debounce 300 ms, один in-flight PUT, очередь последнего значения,
серверная версия. Запоздалый ответ не перетирает локальные более новые фильтры.
При 409 — явное перечитывание; при ошибке не включается неожиданно вся карта.
Settings изолированы по пользователю и компании, deleted layer IDs нормализуются.

Геометрия кабелей имеет отдельный request generation/subscription:

1. «Скрыты» отменяет запрос, очищает массивы, popup references, индексы, feature
   state, GeoJSON hit/halo/line sources, hover и плюс. Pan/zoom/обычный клик не
   вызывают API кабелей. Повторное включение читает актуальный серверный набор.
2. «В области карты» — bbox с текущими SQL-фильтрами, не вся компания.
3. «У выбранного объекта» — один hop физического endpoint, выбор заменяет набор;
   без выбора нет геометрии. Явная кнопка «Показать связи» переводит в этот режим.

Запросы слоя и ошибки также проверяют контекст. При смене компании сначала
очищаются старые данные/выбор/формы. Нельзя скрытием стереть незавершённый route
draft: режим блокируется до его сохранения или отмены. Завершённая форма не
удерживает старую геометрию через историю/draft.

Основная метка `represents` заменяет стандартный дом семантически, не по
координатам. Её ручное членство относится к дому; самостоятельные технические
`reference/located_at` остаются отдельными объектами. Проверка основного
оформления выполняется по dedicated endpoint, а не только по отфильтрованным
точкам экрана. Привязка существующей метки — PATCH, не POST. Действия переместить,
привязать, отвязать, удалить метку и удалить дом явно различаются.

## Основные изменённые файлы

- `components/address-map/address-map.{ts,html,spec.ts}` — интеграция, режимы,
  поколения запросов, отдельные действия, один map instance и overlay.
- `components/map-toolbar/*` — общая панель, фильтры/слои/легенда, tri-state.
- `components/map-layer-editor/*` — диалог CRUD, адресный поиск, порядок/группы.
- `components/map-passport/*` — чтение/редактирование и ручные членства.
- `components/map-legend/map-legend.{ts,html}` — embedded-представление popover.
- `models/map-workspace.models.ts`, `services/map-workspace.state{,.spec}.ts` —
  строгие контракты и маленькое персональное состояние.
- `services/map-data.service{,.spec}.ts` — запросы, ревизии, фильтры.
- `map-connection-layer.ts` — настоящая очистка geometry/hit/halo и индексов.
- `components/map-coordinate-picker/map-coordinate-picker.ts` — защита таймера
  сессии от переполнения, согласованная с основной картой.
- `src/app/shared/address-dependencies-dialog/*` — переиспользованный единый
  диалог адресного раздела и карты, старые проверки сохранены.
- `src/app/pages/addresses/addresses.{ts,html}` — подключение общего диалога и
  синхронизация удаления дома с картой.
- `scripts/verify-map-workspace.mjs`, расширение `verify-map-stage25172.mjs` —
  новые проверки поверх существующего browser runner; старые режимы сохранены.

Первые пути списка относительны `src/app/features/map/`.

## Проверки

```bash
npx ng test --watch=false
npm run build
npm start -- --port 4217 --host 127.0.0.1 --hmr=false --live-reload=false
```

В другом терминале:

```bash
MAP_VERIFY_WORKSPACE=1 MAP_VERIFY_ROUTES=1 MAP_VERIFY_ADDRESS_FIX=1 node scripts/verify-map-stage25172.mjs
```

Используется уже установленный Playwright, Brave headless/SwiftShader; при другом
браузере задайте `MAP_VISUAL_BROWSER=/absolute/path/to/chromium` и при другом
порте `MAP_VISUAL_BASE_URL`. API и тайлы перехватываются локально. PostgreSQL
проверяется backend-тестами отдельно, не подменяется браузерными matching mocks.
DPR 1 — нейтральная street-схема, DPR 2 — локальная неоднородная текстура для
проверки контраста как на спутниковом фоне; живую спутниковую подложку этот тест
не сертифицирует. Скриншоты и JSON: [verification/map-workspace](verification/map-workspace/).

Исходные результаты: 601 frontend/562 backend теста. На этапе добавлены тесты
выгрузки/stale errors/company, повторного включения, one-hop, all-off, сохранения
draft, primary lookup, overlay/focus, предпочтений, паспортов, CRUD/порядка слоёв
и HTTP-контрактов. Имеющиеся проверки split, clipping и прозрачной `note` не
отключались. Отдельного lint target в package.json/angular.json нет.

Production build имеет предупреждение существующего общего initial budget:
~857 kB вместо 500 kB. Лимит не увеличивался и ошибка не подавлялась; сборка
успешна. Это не новый перенос MapLibre в initial bundle — он остаётся lazy.

## Ограничения

Паспорта первой версии не включают файлы, фото, аудит и модель портов/волокон.
Динамические правила ограничены allowlist; полигоны/произвольные схемы не добавлены.
При конфликте предпочтений требуется явное перечитывание, автоматического
слияния вкладок нет. Камера не сохраняется на сервере; сохраняется только
текущая камера при развёртывании одного экземпляра карты.
Элементы Яндекса остаются временно скрытыми по debug-указанию владельца проекта.
Это не решение для production-лицензирования; proxy/cache/secrets не менялись.
