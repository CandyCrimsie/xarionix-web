# Карта: иконки, легенда и вставка муфты

28 октября 2026. Реализация в существующих Angular standalone-компонентах,
Signals, Spartan NG и MapLibre. Модели адресов, viewport API, провайдер тайлов,
существующая кластеризация и глобальная тема не переделывались.

## Каталог и «Заметка»

Без изменения исходной геометрии сохранены восемь SVG:
`map-house`, `network-node`, `cabinet`, `splice`, `pole`, `chamber`, `equipment`,
`note`. `router`, `wifi`, `radio-tower` перерисованы как самостоятельные физические
объекты связи: маршрутизатор, точка доступа и радиомачта. У всех 11 —
`viewBox="0 0 24 24"`, stroke 1.7, скруглённые окончания, отсутствие внутренней
подложки, динамический `currentColor`.

Из основного выбора скрыты дубли/нефизические обозначения:
`house`, `building-2`, `network`, `server`, `hard-drive`, `map-pin`, `cable`,
`wrench`, `zap`, `circle-alert`. Все десять сохраняют прежние SVG и разрешённые
backend ID. При редактировании старой метки её старый вариант присутствует в
выборе; пока его не заменили, он остаётся доступен. Системные пресеты больше не
создают новые метки со скрытыми иконками. Старые сохранённые пресеты работают.

В актуальном `note.svg` уже стояли `fill="none"` у корня и группы; непрозрачной
внутренней заливки там нет. Ошибка отображения возникала в контейнере выбора:
выбранная иконка использовала кнопку `variant="default"` с непрозрачным primary
фоном, а изображение брало цвет из оформления маркера, не из контрастного текста
кнопки. Особенно заметно это было у выбранной по умолчанию «Заметки» в dark theme.
Теперь выбор использует ghost-кнопки с одинаковыми состояниями и единый
`MapIcon`, наследующий цвет интерфейса. Сам SVG не маскировался CSS и не менялся.

Исправлена отдельная ошибка `pickMarkerAppearance`: явное `icon_name=null`
раньше подменялось значением `note` через `??`. Теперь «Без иконки» действительно
остаётся без иконки; false и нулевые прозрачности также сохраняются.

Сетка: фиксированные 44×44 CSS px, SVG 24×24, выбранное состояние через
`aria-pressed`/`data-selected`, одинаковые border/hover/focus/disabled. Названия
доступны через русские Spartan tooltip. HTML всех новых компонентов вынесен
в отдельные `.html`.

## Легенда

`MapLegend` использует установленный `HlmCollapsible` (`expanded`), `HlmButton`,
`HlmTooltip`, `HlmSeparator`. Это компактный glass-overlay 240 px с тёмной
полупрозрачной поверхностью и blur. По умолчанию свёрнут; раскрывается доступной
кнопкой, содержимое ограничено по высоте и прокручивается. Расположен выше
логотипа/attribution; настройки слоёв не добавлялись.

Выводятся только видимые иконки, среды и статусы. Линии и легенда используют
общие `CONNECTION_COLORS` и `CONNECTION_STATUSES`, включая реальные dash patterns
и opacity. Объекты без координат и отключённые фильтрами категории не добавляют
ложные обозначения. Дублирующиеся иконки показываются один раз.

API компонентов сверялось с официальными страницами:
[Collapsible](https://www.spartan.ng/components/collapsible),
[Tooltip](https://www.spartan.ng/components/tooltip),
[Popover](https://www.spartan.ng/components/popover),
[Button](https://www.spartan.ng/components/button),
[Separator](https://www.spartan.ng/components/separator).
Использованы фактические импорты и API из локальных `libs/ui`.

## Плюс и геометрия

Одна прозрачная line hit-layer шириной 18 px, один Angular overlay на весь граф.
Отдельные DOM-маркеры/Angular-компоненты для каждой линии не создаются.
Обработчик `queryRenderedFeatures` получает ID кандидатов; точка вычисляется по
полной исходной геометрии, а не упрощённому feature тайла.

`nearestRoutePoint()` проецирует каждый сегмент через MapLibre `project()`,
ищет ортогональную проекцию курсора с ограничением t на [0,1], пропускает нулевые
сегменты, выбирает ближайший и вызывает `unproject()`. Для backend доля
пересчитывается в координатах Web Mercator, поэтому она корректна и при наклоне
камеры. Позиция не подменяется серединой линии или ближайшей вершиной.

Плюс 32 px следует за курсором, в том числе когда события уже получает сама
кнопка. Grace period 140 ms не даёт ему исчезать при переходе с линии на кнопку.
CSS-анимация применяется только к цветам: `transition-all` и смещение кнопки при
active не могут сдвигать геометрическую точку клика.

При наложении предлагается выбрать ровно одно соединение. Плюс переставляется
на выбранную линию, получает клавиатурный фокус и требует подтверждения. Это
важно для соседних кабелей: форма открывается только после фиксации точки
именно на выбранной трассе. При движении вдоль выбранного кабеля выбор сохраняется.

Плюс скрыт при редактировании/рисовании, размещении метки, открытом диалоге,
перемещении камеры и без права создавать техническую муфту. Слушатели и таймер
удаляются вместе с картой. Альтернатива для touch/клавиатуры — «Вставить муфту»
в карточке соединения: явный выбор участка и положения на нём, затем та же форма.

## Сохранение

Переиспользуется `MapMarkerEditor` с контекстом выбранного соединения. Тип
`splice`, координаты, видимость и отсутствие привязки к дому зафиксированы;
название, описание и оформление доступны. Отмена ничего не записывает.

`MapDataService.splitConnection()` вызывает специализированный защищённый
backend endpoint. Передаются версия, `geometry_token`, индекс сегмента, доля,
точка и только описательно-визуальные поля муфты. Поле `geometry_token` —
совместимое дополнение к существующему ответу соединения.

Один успешный ответ содержит реальную муфту и оба участка; обновляются только
соответствующие sources, сохраняется камера, появляется Sonner toast. Старые
viewport-запросы инвалидируются до применения ответа. Ошибка не закрывает форму;
повторное сохранение во время запроса заблокировано. Смена компании и уничтожение
компонента делают старые ответы неактуальными.

Транзакции, блокировки, точность и PostgreSQL-тесты описаны в соседнем backend
репозитории `docs/map-connection-split.md`. Миграция БД не требуется.

## Ограничения

Создание технической муфты требует прежнего `addresses.manage`, в том числе на
личной линии. Чужая личная линия недоступна. При конфликте версии/перемещении
конца нужно закрыть форму и выбрать точку заново: система не сдвигает её молча.
Допуск хранения — существующие 7 знаков координат, минимум 1 м до концов по
трассе. Polar/antimeridian insertion отклоняется явно; большие карты и управление
слоями остаются отдельным этапом. Учёт сварок/волокон/портов не реализовывался.
