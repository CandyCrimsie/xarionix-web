# Карта: hit-testing, границы прокладки и Spartan UI

29 октября 2026. Основа: frontend `37a5b78`, backend `f999a57`.
Незакоммиченных пользовательских изменений перед работой не было.
Новые библиотеки, глобальные токены, модель адресов, RBAC и карта-провайдер
не менялись. Скрытая в debug атрибуция Яндекса не восстановлена.

## Подтверждённые причины

1. `connectionFootprints()` читал только `queryRenderedFeatures`. После split
   канонический ответ уже содержал новую метку, но GeoJSON worker ещё не
   предоставлял её для hit-testing. Пересборка индекса также откладывалась до RAF.
2. На уже существующем marker-plus hover действовала задержка ухода 140 мс,
   а `held` проверялся раньше occlusion. Инструмент вставки мог оставаться
   поверх метки. Hover кабеля тоже не проверял footprint.
3. При наличии определений слоёв ответ split не добавлял новый объект в
   локальные маркеры до следующей загрузки viewport.
4. Границы существовали как методы соседних сегментов, но не имели
   интерактивного представления. Удаление геометрической вершины вместо
   изменения метаданных могло бы срезать угол — новый редактор этого не делает.
5. Стрелки легенды были статическими; connection editor использовал native
   details/summary. Меню плюса уже было Spartan Popover, а не кастомным overlay.
6. Перестановка концов уже разворачивала геометрию и методы правильно.
   Гипотеза об ошибке этого алгоритма не подтвердилась; добавлены UI проверки.
7. Нечисловой ввод координат мог оставить прежнее значение доступным для
   сохранения, а пустая строка превращалась в 0. Теперь такой ввод блокирует
   сохранение, пустое поле означает NULL, ошибки показаны рядом с полями.
8. Escape непосредственно после закрытия Popover мог поглощаться его exit
   animation. Активное размещение теперь владеет отменой; полноэкранный
   контейнер не принимается за вложенную модальную форму.
9. Режим прокладки мог пережить смену выбранного/доступного кабеля и поглотить
   следующий Escape в fullscreen. Режим без активного черновика теперь
   завершается, если его кабель больше не выбран/не виден. Активный черновик
   при этом не уничтожается молча.

## Приоритет интерактивности

После мутации синхронно сбрасываются plus/menu state и поколение callback,
обновляются канонические маркеры и пространственный индекс. Пока worker не
отрисовал точки, учитываются канонические координаты; новые объекты защищены
также на clustered zoom. Поздние viewport ответы инвалидируются.

Клиппинг линий продолжает использовать фактические alpha bounds/форму. Для
**интерактивности** существует отдельный footprint: полный размер символа,
прозрачные отступы и запас под 32px кнопку. Проверяются и положение курсора,
и точка привязанного плюса. Метка имеет приоритет над click/hover кабеля.
Hit-геометрия трассы и PostgreSQL координаты не обрезаются.

## Границы прокладки

Переходы видны у загруженных трасс без предварительного выбора: отдельный
GeoJSON source и два MapLibre circle layers, непрозрачный тёмный круг 12px
со светлой обводкой и центром. DOM handles с tooltip «до → после» существуют
только у выбранного соединения — это не инфраструктурные узлы. Карточка предлагает
«Редактировать прокладку»; в режиме остаются кнопка выхода и добавление
новой границы прежним плюсом.

Spartan Popover границы позволяет изменить способ после точки, перенести
границу или объединить участки с явным выбором предыдущего/следующего способа.
Одинаковые соседние способы автоматически перестают образовывать границу.
Перенос: snap по полной полилинии → живой preview → щелчок для фиксации →
«Сохранить». Escape/«Отмена» не делают HTTP mutation. Порядок границ и минимум
1 м проверяются клиентом и сервером. Все старые углы сохраняются.

Сохраняется прежний массив `installation_methods`; новая таблица/миграция
не требуется. Новый backend PATCH описан в `xarionix-erp/docs/map-installation-boundaries.md`.
Запросы используют замороженные version/token/segment/fraction/position.
Повторное сохранение блокируется, смена компании инвалидирует ответы.

## Интерфейс

- Маркер: компактные вкладки, основная информация и отдельная группа
  расположения, inline latitude/longitude + icon button, preview без второй
  карты, одинаковая SVG-сетка; личные стили и прозрачность — Collapsible.
- Соединение: название сверху, icon-only swap между концами, одинаковые
  Spartan Collapsible для участков и вершин, компактные действия с tooltip,
  прокручиваемое тело и доступный footer.
- Легенда: фактическое состояние Right/Down у всех раскрываемых секций;
  образцы используют прежний общий `map-line-styles` и SVG renderer.
- Слои: компактный заголовок и вложенная справка Info в Spartan Popover.
- Панели используют theme tokens. По уточнённому пожеланию пользователя плюс
  сохраняет прежнюю тёмную картографическую поверхность и не светлеет при hover.
  Фон handles непрозрачен: Outline с `dark:bg-input/30` заменён локальным
  оформлением геометрической кнопки без изменения размера.
- Разворачивание: квадратная icon-only кнопка без постоянного tooltip-текста;
  прежний DomPortal, p-4, тот же MapLibre instance/камера/выбор/draft.

Стандартные элементы — установленный Spartan NG 1.3.4. Кастомными остаются
только MapLibre-отрисовка, геометрические handles/preview и позиция единственного
hover overlay. Outside-click, focus и Escape popover/dialog не реализуются заново.

## Ограничения

Старая вершина после переноса/удаления границы намеренно сохраняется как
геометрическая. Автоупрощение трасс и множественное массовое редактирование не
добавлены. Редактируемые handles существуют только у одного выбранного кабеля;
у остальных загруженных трасс — лёгкие MapLibre обозначения, не DOM редакторы.
Нативный touch/аппаратный GPU требуют отдельной ручной
проверки: автоматический браузер использует SwiftShader.
