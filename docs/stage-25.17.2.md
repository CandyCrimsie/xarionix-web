# Stage 25.17.2 — frontend и проверка карты

## Что изменено

Редактор меток разделяет тип объекта, видимость и роль связи с домом. Выбор картинки
не меняет тип. Выбор дома подготавливает справочную связь, а основная роль выбирается
явно. Для расположенного дома отдельное действие «Изменить расположение дома»;
для нерасположенного — явный выбор/ввод точки. Технического переключателя sync больше нет.

409 перепривязки открывает Spartan confirmation с полным адресом, старой меткой,
прежним домом и старой/новой точками. Отмена не вызывает запись; подтверждение отправляет
серверный snapshot-token, не force. Ошибка не стирает черновик.

Компания/private и `can_manage` определяют доступные действия. Читатель создаёт
собственные заметки и личные линии, но не общие инфраструктурные объекты.
Кнопки не заменяют серверную авторизацию.

На карте: компактные действия добавления точки/соединения, фильтры домов,
инфраструктуры, личных точек, среды и статуса линий, легенда. Co-located объекты
различаются по kind+id и доступны через список выбора. Основная метка дома всегда
открывает карточку дома; reference/located_at не скрывают стандартный домик.

Карточка точки содержит тип, имя, описание, координаты, полный связанный адрес/роль,
переход к дому и присоединённые линии. Карточка линии содержит среду, состояние,
параметры кабеля, концы с переходами и «Длина трассы по карте».
Отсутствие координат — отдельное состояние, не фиктивная точка 0/0.

## Соединения

Spartan-форма: два типизированных конца через поиск/нажатие на карту, обмен концов,
среда, состояние, параметры, описание, видимость. Смена среды очищает чужие параметры.
На карте можно добавлять/таскать/удалять промежуточные вершины, отменять правку.
Дополнительно есть ручной ввод «широта, долгота» и undo. GeoJSON всегда [longitude, latitude].
Enter завершает текущий режим выбора, Escape отменяет без записи, Delete удаляет
только выбранную внутреннюю вершину. Сохранение явное; камера не сбрасывается.

Отдельные GeoJSON sources/layers для сети, черновика и ручек. FO — индиго #5A67D8,
UTP — #16888A; active сплошная, planned пунктир, construction штрих/точки,
inactive приглушённая. Подписи формируются из реального fiber_count/category.
Удаление с подтверждением, зависимости блокируют удаление занятой точки.

## Оформление и личные стили

Восемь исходных SVG сохранены в `src/app/features/map/icons/` без изменения геометрии.
Для нового стандартного дома используется `map-house`, а старый Lucide ID `house`
сохранён с прежним значением. Иконки контролов остаются Lucide.

`map-marker-renderer.ts` — один SVG renderer для preview, sprite, стандартного дома,
drag-preview и selected-состояния. Нормальный символ 24×24 в 32 CSS px, 26/40 для
маленького/большого; тонкая граница, theme palette и мягкий selected halo.
Отдельно сохраняются цвет/непрозрачность иконки и подписи, фон и обводка с выключением,
общий opacity, размер/форма; подпись под символом, не слева. Pill — широкая подложка,
подпись остаётся снаружи (режим текста внутри pill не вводился).

Сохранённые точки — MapLibre symbols, не Angular component на каждую точку.
SVG rasterization 2x обеспечивает Retina. Полный канонический ключ стиля исключает
коллизии; label и общий opacity не создают текстур. Неиспользуемые изображения удаляются,
асинхронные изображения устаревшего состояния не попадают в карту.
Пользовательский HTML/SVG/URL не принимается, текст не вставляется через innerHTML.

«Мои стили»: сохранить, применить, переименовать/сохранить изменения, дублировать,
удалить с подтверждением, сбросить оформление. В preset копируется только appearance,
не тип/координаты/дом/владелец/права. Стили хранятся через backend в PostgreSQL.
Изменение пресета не изменяет уже сохранённые метки.

Вкладки «Основное / Иконка / Оформление», поиск иконок с tooltip, понятная геометрия
hlm-field-group и прокрутка формы. Палитра ERP глобально не переопределялась.
В layout заменён жёсткий `text-zinc-50` на theme-token `text-foreground`: это исправляет
невидимый белый текст в светлом режиме, сохраняя тёмную тему.

## Исправленные дефекты

- Первый запрос объектов больше не пропускается из-за временного isStyleLoaded=false
  после создания sources. То же исправлено для фокуса города/улицы.
- Локальный Golos Text (OFL, лицензия рядом с TTF), корректный массив `font-faces`
  установленной MapLibre 6.15: кириллица и cluster count проверяются настоящим браузером.
- Восстановлены предусмотренные интеграцией логотип/ссылки Яндекса.
- Drag-preview имеет точный размер, поэтому центр символа совпадает с географической
  точкой (проверяется с допуском <1 CSS px); контраст подписей учитывает цвет текста.
- Enter в endpoint-picker выбирает подсказку без лишнего HTTP-запроса и повторного
  открытия overlay. Стандартное оформление primary-дома переиспользует домовой sprite.
- Смена компании закрывает редакторы/подтверждения, очищает личные данные, черновики,
  saving/deleting/selection, инвалидирует старые HTTP-ответы.
- Отложенные popup/стиль-навигация и cluster expansion не применяют старое состояние.
- Tile-session single-flight; временная ошибка — максимум четыре backoff retry
  (2/4/8/16 секунд), затем явное «Повторить». Нет перезагрузки карты на каждый tile error.
- При уничтожении освобождаются карта/WebGL, popup views, observers, handlers и timers.
- Координатный picker использует тот же renderer и оформление основной метки дома.
  При смене компании он закрывается и отбрасывает старые события/выбранную точку.

Смешанный адресный поиск, дерево, company Locations и существующая навигация не переписаны.

таскаются мышью; для touch/клавиатуры есть ручной ввод координат и отмена.
