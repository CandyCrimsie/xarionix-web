# Карта телеком-инфраструктуры: объекты на трассе и прокладка

Реализация 28 октября 2026. Основа — существующая карта, SVG-рендерер,
редактор маркеров, split и SpartanNG. Новая библиотека UI/карт не подключалась.

## Работа на карте

1. Наведите курсор на кабель. Один переиспользуемый плюс 32 px следует за
   ближайшей точкой полной полилинии, а не её центром или вершинами.
2. Нажмите плюс: снимок соединения и точка фиксируются. Откроется небольшой
   Spartan Popover с двумя явно разделёнными действиями.
3. **Сетевой узел — разделить кабель:** муфта, бокс, кросс, узел связи, шкаф.
   **Вдоль трассы — без разрыва:** колодец, опора, точка перехода.
4. Открывается прежний редактор метки с уже заданными координатами. Для бокса,
   узла и шкафа роль можно осмысленно переключить в форме. Отмена ничего не пишет.
5. Альтернатива без hover — «Добавить на трассу» в карточке соединения:
   выберите сегмент и положение, затем объект в том же меню.

Пересекающиеся/наложенные линии требуют явного выбора одной трассы.
Данные запроса: ID, версия, geometry token, индекс сегмента, Mercator fraction,
координаты. Mousemove после открытия меню/формы не меняет снимок.
У плюса 140 ms grace-period и удержание при переносе курсора на кнопку;
нажатие не передаёт click/drag карте. Во время других редакторов/движения камеры
плюс скрыт. При новом наведении snap пересчитывается с текущей проекцией камеры.
Без права управления техническая операция недоступна и в меню, и на сервере.

При успехе обновляются затронутые записи GeoJSON, отменяются старые viewport
запросы, сохраняются камера и дерево. Конфликт/ошибка оставляет форму и введённые
значения. Смена компании инвалидирует меню, диалоги и запоздалые ответы.

## Способы прокладки

В редакторе соединения есть способ для всей трассы и раскрываемые «Участки
прокладки». У каждого сегмента свой Select и точный SVG-preview линии.

Из меню плюса «Изменить прокладку отсюда…» можно добавить границу в любой точке
сегмента, без физического узла. Действие применяется до следующей вершины или
до конца кабеля. Колодец/опора/переход также могут установить прокладку после
себя, не разрывая кабель. Тип кабеля и состояние при этом сохраняются.

В черновике `installation_methods` соответствует рёбрам `[source,*vertices,target]`.
Вставка вершины наследует способ сегмента, перемещение сохраняет его,
разворот разворачивает массив. Удалить границу разных способов можно только
после выбора способа объединённого участка. Undo восстанавливает геометрию
и способы вместе; старые варианты без массива явно показываются как «Не указан».

Привязанные объекты показаны в карточке соединения. Доступна явная отвязка с
подтверждением — самостоятельная метка остаётся в прежней точке. Геометрию,
уходящую в сторону от закреплённого объекта, сервер не сохраняет молча.
Смена типа/положения/видимости закреплённой метки заблокирована до отвязки,
но оформление и название редактируются.

## Единый визуальный язык

`map-line-styles.ts` — общий декларативный источник для MapLibre и SVG-легенды.

| Признак | Отображение |
| --- | --- |
| Оптоволокно / UTP | `#4F9DD9` / `#D6A66B` |
| Выделение | `#EAF4FF`, мягкий halo только hover/selected |
| Обычная ширина | 2.7 px при zoom 16, плавная zoom-интерполяция |
| Hover / selected | +0.6 / +0.9 px |
| Unknown / aerial | Сплошная |
| Duct | `[3,1.8]` |
| Direct buried | `[0.35,1.8]` |
| Facade | `[5,1.5,0.5,1.5]` |
| Indoor | Тонкая сплошная, 1.8 px |
| Planned / construction / active / inactive | opacity 0.5 / 0.8 / 1 / 0.28 |

Dash arrays — единицы **ширины линии**, не пиксели. SVG использует тот же
массив, умноженный на толщину образца. Статус не подменяет рисунок прокладки.
Соседние одинаковые способы объединяются в полилинию с round join/cap, без
случайных двойных сегментов. Активный черновик заменяет отображение редактируемой
линии, а не рисуется вторым слоем поверх неё.

Шесть фиксированных method layers используют общий GeoJSON-источник; нет
DOM-элемента/Angular view для каждого кабеля или сегмента. Feature-state
обновляется только при изменении hover/selection, старые состояния фрагментов
очищаются. Клиппинг объединяется через requestAnimationFrame. События raster
тайлов не вызывают лишнюю пересборку линий.

## Линии под прозрачными маркерами

Линии/halo/подписи кабелей располагаются до слоёв точек. Дополнительно
`map-line-clipping.ts` вычитает экранные footprint маркеров из **отображаемой**
геометрии. Для circle/rounded/pill учитываются реальные размеры и скругления;
для отдельной иконки — alpha bounds существующего sprite, с ограниченным кэшем.
Учитываются выделение, несколько подходящих линий, проходной объект и кластеры
уже существующей карты. Новый механизм кластеризации не добавлялся.

Результат обратно проецируется в географические координаты только для render
source. Геометрия PostgreSQL и отдельный full hit source остаются исходными.
Snap и серверный split используют полную трассу, не клиппированные куски.
Нет маски с цветом подложки; внутри прозрачной иконки остаётся настоящая карта,
без просвечивающего кабеля. Разреженная screen-grid ограничивает поиск
пересечений footprint в пределах viewport, включая очень длинные сегменты.
После смены zoom/размеров/данных точек клиппинг пересчитывается. Широкий halo
использует отдельный cut и маленький источник только для выделенной/наведённой
трассы: он не просвечивает под меткой и не увеличивает зазор основной линии.

## Иконки и легенда

Добавлены специализированные SVG `fiber-box`, `odf`, `transition`: viewBox 24,
stroke 1.7, прозрачный фон, динамический цвет. Прежние восемь специализированных
и три дополнительных telecom-иконки не перерисованы. Старые скрытые варианты
остаются доступны при редактировании существующей метки. Все новые варианты
попадают в ту же сетку 44×44 с центрированным SVG 24×24 и русскими tooltip.

Легенда остаётся небольшой тёмной glass-панелью с Spartan Collapsible,
показывает используемые объекты, среды, способы и состояния. Раздел способов
сворачивается отдельно; длинное содержимое ограничено высотой и прокручивается.
Attribution провайдера не перекрывается. Управление слоями не реализовывалось.

## Ограничения

Нет учёта волокон/сварок/портов, PostGIS, новых слоёв управления или новой
кластеризации. Минимальные длины и ограничения Mercator сохранены. Точка с
несколькими проходящими кабелями не соединяет их автоматически. Для переноса
привязанного объекта вне трассы требуется явная отвязка; фоновые попытки
угадывать его новое положение не выполняются. Проверка подложки использует
контрастную неоднородную тестовую raster-сетку, не реальные Yandex tiles.
